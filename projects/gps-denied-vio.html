Project overview

The project addresses the following problem: A ROS 2 mission stack that monitors pose freshness and jumps, follows waypoints, and holds when localization is lost. Deterministic software validation exercises an injected VIO dropout and recovery; these results are synthetic closed-loop tests, with simulator and flight integration still to be evaluated.

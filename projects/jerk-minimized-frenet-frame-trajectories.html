Jerk-minimized Frenet-frame trajectories

Project overview

The project addresses the following problem: Local trajectory optimization in the road-aligned Frenet frame using quintic/quartic polynomials for jerk-minimizing paths, with a risk-aware Gaussian cost and time-indexed collision checking for dynamic obstacles — about 16× safer time-to-collision than hard collision filtering while keeping the lowest jerk across six scenarios.

Project overview

The project addresses the following problem: A quadcopter platform that can fly and drive using a servo mechanism that tilts the motor arms. LiDAR generates point clouds for 3D mapping in difficult spaces, and a modular attachment slot adapts the platform for different missions.

Approach and tools

Drone · Arduino · LiDAR · Point cloud · ArduPilot

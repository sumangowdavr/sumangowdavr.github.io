Project overview

The project addresses the following problem: A differential-drive simulation with camera, lidar and IMU bridges, guarded velocity commands and a target-point follower. The public package includes 14 controller tests, model checks and an isolated Gazebo smoke-test runner. Passive supports stabilize the base; this prototype does not implement self-balancing or visual person detection.

Approach and tools

ROS 2 Humble · Gazebo Fortress · Command guard · 14 tests

The implementation combines the project-specific design with software, sensing or experimental methods relevant to the task. Consult the repository and reports below for source-level details.

Evidence and scope

The recorded Gazebo smoke test passed checks for camera, lidar, IMU, forward motion, turning and watchdog stopping. It tests a supported base and odometry; it does not demonstrate self-balancing.
